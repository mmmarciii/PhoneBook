## 🚀 Functions

- **CRUD operations:** View, add, delete, and update contact records...
- **Interactive menu:** User-friendly menu system navigable with arrow keys.
- **Phone Number validation:** Validation:(`libphonenumber-csharp`).
- **Databes:** SQLite/SQL Server integration via Entity Framework Core.

## 🛠️ Tech stack

- **Language:** C# (.NET 10)
- **ORM:** Entity Framework Core
- **UI:** [Spectre.Console](https://spectreconsole.net/)
- **Validation:** Libphonenumber-csharp
